# Changelog - CINEMA ELK 2.0

All notable changes to this project are documented in this file.

## [2.0.0] - 2026-07-25
### Added
- Complete rewrite of Cinema Elk platform on React 18, Vite, Tailwind CSS v3, Express.js, and Firebase.
- Glassmorphic UI design system with dynamic dark/light mode toggling.
- TMDB v3 API integration with user credentials and high-res backdrop engine.
- Interactive Chart.js Admin Dashboard with growth metrics and genre distribution charts.
- Role-based authorization system (Guest, User, Moderator, Administrator).
- Comprehensive 12-file documentation suite.
