# Product Requirement Document (PRD) - CINEMA ELK 2.0

## 1. Executive Summary
CINEMA ELK 2.0 is an enterprise film discovery platform combining live movie metadata, interactive community reviews, personalized watchlists, and administrative analytics.

## 2. User Roles & Persona
- **Guest**: Browse trending films, view movie details, trailers, and cast info.
- **User**: Save watchlists/favorites, submit star ratings and markdown reviews, like community posts, follow critics.
- **Moderator**: Manage content reports, flag inappropriate reviews, moderate comments.
- **Administrator**: Full system access, view analytics charts, manage user roles, audit activity logs.

## 3. Core Features
- Hero Carousel Banner with Framer Motion transitions.
- Global Multi-Filter Search (Movie, Genre, Year, Rating).
- Star & Half-Star Rating System with Distribution Chart.
- Real-Time Watchlist & Favorites Sync.
- Interactive Admin Console with Chart.js.
